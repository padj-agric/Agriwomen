# 🌾 Agriwomen

**Agriwomen** is a web platform dedicated to empowering young girls and women through agriculture, entrepreneurship, food security, climate adaptation, and the fight against violence.

## 🚀 Project Objectives
* **Economic Empowerment**: Encouraging women-led agricultural entrepreneurship.
* **Food Security**: Developing sustainable and efficient food production techniques.
* **Climate Resilience**: Providing training on adaptation practices to tackle climate change.

## 🛠️ Built With
This website was fully developed on mobile using core web technologies:
* **HTML5**: For the overall structure and textual content.
* **CSS3**: For the modern design, signature green themes, and mobile responsive layouts.
